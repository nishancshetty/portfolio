# AI Portfolio Chatbot – Case Study

## Problem

Traditional portfolio websites are static. Visitors have to browse multiple pages to learn about the developer, projects, and skills. I wanted to create a more interactive experience where recruiters and visitors could ask questions naturally and receive instant answers.

## Solution

I built an AI-powered portfolio chatbot that acts as a personal assistant. It understands questions about me, my projects, skills, education, and contact information, then responds with relevant answers in real time using a large language model. The chatbot streams responses for a smooth user experience and integrates directly into my portfolio website.

## Tech Stack

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS
* AI SDK
* Google Gemini API
* Vercel (Deployment)
* Git & GitHub

## Challenges

One of the biggest challenges was integrating AI response streaming into the chat interface while keeping the UI responsive. I also had to manage API keys securely using environment variables and handle issues related to model availability and API configuration. Another challenge was designing a system prompt that allowed the AI to answer accurately about my portfolio without generating incorrect information.

## Result

The final application provides visitors with an interactive way to explore my portfolio. Instead of searching through pages, they can ask questions such as "Tell me about Nishan," "What projects have you built?" or "How can I contact you?" and receive immediate responses. This project strengthened my understanding of AI integration, API development, modern React patterns, and deploying production-ready applications.
